# Mini CRM System

A full-stack Customer Relationship Management (CRM) application built using the MERN stack. The system helps businesses manage leads, convert them into customers, track follow-ups, manage products and orders, and monitor business activities through a dashboard.

## Features

- User Authentication (Login & Register)
- Dashboard with Analytics
- Lead Management
  - Add Lead
  - View Leads
  - Delete Lead
  - Convert Lead to Customer
  - Update Lead Status
  - Follow-up Date
  - Follow-up Notes
- User Management
- Product Management
- Order Management
- Search Functionality
- Responsive User Interface

## Installation

### Clone Repository

```bash
git clone https://github.com/Bhoomikagowda06/FUTURE_FS_02.git
```

### Backend

```bash
cd server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```
